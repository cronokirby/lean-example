# lean_example

A small Lean 4 project without dependencies: a binary tree with a few proved lemmas, some
propositional logic, and an executable.

```sh
lake build
lake exe lean_example
```

Open `LeanExample/Basic.lean` in Helix and run `lean-tui` in a second terminal to see proof
states. Editor setup: `~/Work/lean-tools/README.md`.
