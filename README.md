# lean-example

Verifying Rust in Lean with [Aeneas](https://github.com/AeneasVerif/aeneas).

- `examples/src`: the Rust crate, with property functions that should return `true` for every
  input.
  - `merkle.rs`: a Merkle tree generic over a `Hash` trait.
  - `nsl.rs`: the Needham–Schroeder–Lowe protocol generic over public-key encryption, run in a
    real, an ideal (IND-CCA) and a symbolic world, with its secrecy game.
- `examples/tests/nsl.rs`: fuzz tests (proptest) for the NSL properties. The adversary builds
  messages from what it has seen; against the original Needham–Schroeder it finds Lowe's attack.
- `examples/lean-src`: the Lean project. `Examples/Gen` is generated by `./extract.sh`
  (Charon + Aeneas); never edit it by hand. `Examples/Merkle.lean` and `Examples/Nsl.lean`
  state everything that is proved; the proofs live in `Examples/Merkle/` and `Examples/Nsl/`.
  For NSL that is: symbolic secrecy and faithfulness for every input, Lowe's attack on the
  original protocol, and the concrete bound
  `Pr[win] ≤ advCCA(reduction) + q(q+1)/2^64` against every adversary.

```sh
cargo test
cd examples/lean-src && ./extract.sh && lake build
```
