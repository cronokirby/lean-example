# lean-example

Verifying Rust in Lean with [Aeneas](https://github.com/AeneasVerif/aeneas).

- `examples/src`: the Rust crate (`merkle.rs`: a Merkle tree generic over a `Hash` trait,
  plus property functions that should return `true` for every input).
- `examples/lean-src`: the Lean project. `Examples/Gen` is generated by `./extract.sh`
  (Charon + Aeneas); never edit it by hand. `Examples/Merkle.lean` states everything that is
  proved; the proofs live in `Examples/Merkle/`.

```sh
cargo build
cd examples/lean-src && ./extract.sh && lake build
```
